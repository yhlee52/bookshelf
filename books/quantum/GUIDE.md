# 『차근차근 양자역학』 집필 가이드

이 책의 모든 장이 따르는 규칙입니다. 장을 쓰기 전에 이 문서와 [`templates/textbook.html`](../../templates/textbook.html)을 먼저 봅니다.

## 1. 책의 성격

- **가장 먼저 지킬 원칙은 독자에게 내용을 쉽고 정확하게 전달하는 것입니다.** 다른 모든 규칙은 이 원칙 아래에 둡니다. 새 개념은 왜 필요한지부터 말하고, 화살표 같은 익숙한 예에서 출발해 넓혀 가며, 손으로 따라 할 수 있는 숫자 예제로 확인합니다.
- **이론서**입니다. 각 절은 정의, 유도, 예제 순서로 진행합니다. 실험(시뮬레이션)은 억지로 넣지 않습니다. 정적인 그림이나 예제로 전달하기 어려운 곳에만 넣습니다. 예를 들어 7장의 파속 퍼짐과 터널링, 16장의 스핀 세차 운동입니다.
- **독자**는 물리학과 학부 2~3학년입니다. 미적분, 기초 선형대수, 일반물리 수준의 역학과 전자기학을 안다고 가정합니다.
- **뼈대**는 샨카(*Principles of Quantum Mechanics*, 2nd ed.)의 순서입니다. 수학 도구는 처음 필요한 자리에서 **수학 상자**로 설명합니다. 보아스(*Mathematical Methods in the Physical Sciences*)가 하는 역할입니다.
- **원칙**: 교재의 순서와 주제는 따르되 문장, 예제, 연습문제, 그림은 새로 씁니다. 교재의 문장이나 문제를 옮기지 않습니다.
- 이 책을 마친 뒤에는 심화 양자역학(2권)으로 이어갈 수 있습니다. 상대론적 장론이나 2차 양자화처럼 범위 밖의 주제는 그쪽으로 미룹니다.

## 2. 목차

목차의 기준은 [`data/books.js`](../../data/books.js)의 `quantum` 항목입니다. 6부 23장으로 되어 있습니다.

- `parts`에는 부 제목과 설명이 있습니다. 각 장은 `part`로 자기 부를 가리킵니다.
- 아직 쓰지 않은 장(`status: "slot"`)의 `desc`에는 그 장의 절 목록이 `·`로 구분되어 있습니다. 장을 다 쓰면 `desc`를 한두 문장 요약으로 바꾸고 `status`를 `"draft"`로 올립니다. `"done"`은 사용자가 확인한 뒤에 바꿉니다.
- 쓰는 도중 절을 나누거나 합칠 수 있습니다. 그때는 이 문서의 장 목록과 `books.js`를 함께 고칩니다.

## 3. 장 한 편의 구성

| 부분 | 내용 | 분량 기준 |
|---|---|---|
| 머리 | 리드 문단(2~3문장), 학습 목표, 선수 지식 | 학습 목표 3~5개 |
| 절 n.1 … n.k | 동기 → 정의 → 유도/정리 → 예제 → (그림, 콜아웃) | 장당 절 3~7개 |
| 핵심 정리 | 장 전체의 요점 | 5~8개 |
| 확인 퀴즈 | 개념 확인용 객관식 문항과 해설 | 4~6문항 |
| 연습문제 | 난이도 ★1~3, 풀이는 접어 둠 | 6~12문제 |

- **유도는 중간 단계를 건너뛰지 않습니다.** "쉽게 보일 수 있다"로 넘기지 않습니다. 길어지면 단계마다 번호 식을 두고 참조합니다.
- 장의 중심 유도는 본문에 펼쳐 쓰고, 곁가지 증명만 `details.proof`로 접습니다.
- 예제의 풀이는 펼쳐 두고, 연습문제의 풀이는 `details.sol`로 접습니다.
- 앞 장의 결과를 쓸 때는 링크로 가리킵니다. 예: `<a href="ch02.html#thm-spectral">정리 2.3</a>`.

## 4. 부품과 번호

번호는 `assets/js/book.js`의 `textbook()`이 자동으로 붙입니다. 손으로 번호를 쓰지 않습니다.

| 부품 | HTML | 자동 번호 |
|---|---|---|
| 절 | `<section id="s1"><h2>제목</h2>…</section>` | 1.1, 1.2 … |
| 정의 · 정리 · 예제 · 수학 상자 | `<div class="box def\|thm\|ex\|math" id="…"><div class="box-h">이름</div>…</div>` | 정의 1.1, 정리 1.1 … (종류마다 따로 셈) |
| 번호 식 | `<div class="formula" id="eq-…">\[ … \]</div>` | (1.1), (1.2) … (`id`가 있는 식만) |
| 연습문제 | `<div class="prob" id="prob-…" data-level="2">…</div>` | 문제 1.1 … |
| 참조 | `<a class="ref" href="#eq-…"></a>` (비워 둠) | 위 번호로 채워짐 |
| 증명 · 풀이 접기 | `<details class="proof\|sol"><summary>증명</summary>…</details>` | |
| 콜아웃 | `<div class="callout tip\|warn\|deep">` | 직관 · 흔한 실수 · 심화 |

`id`는 내용을 따서 짓습니다. 예: `def-inner-product`, `eq-schrodinger`, `thm-spectral`. 번호는 바뀌어도 `id`는 바뀌지 않게 하려는 것입니다.

## 5. 표기 규칙

기준은 책 홈의 [표기 규칙](index.html#notation) 표입니다. 요점은 다음과 같습니다.

- 디랙 표기를 1장부터 씁니다. 내적은 왼쪽 자리에 대해 켤레 선형입니다.
- 연산자에는 모자를 씌웁니다(`\hat\Omega`). 고유값과 숫자에는 씌우지 않습니다.
- 단위는 SI입니다. 샨카는 가우스 단위를 쓰므로, 수소 원자·제이만 효과처럼 전자기가 나오는 장에서는 차이를 본문에 밝힙니다.
- 푸리에 변환은 `1/\sqrt{2\pi\hbar}` 대칭 관례를 씁니다.
- 용어는 한국물리학회 용어를 따르고, 처음 나올 때 영어를 함께 적습니다. 예: `<span class="term">고유값</span> <span class="en">(eigenvalue)</span>`.

## 6. 검증

- 유도의 각 단계, 고유값, 적분, 교환자는 기호 계산(sympy)이나 수치 계산으로 따로 검산합니다. 검산 스크립트는 저장소에 넣지 않습니다.
- 그림 속 곡선(파동함수, 퍼텐셜, 확률 분포)은 실제 식으로 계산해 그립니다. 눈대중으로 그리지 않습니다.
- 물리 상수는 CODATA 권장값을 씁니다. 근삿값을 쓸 때는 유효숫자를 밝힙니다.
- 교재와 관례(단위, 부호, 정규화)가 다른 곳은 본문에 적습니다.
- 페이지 점검 항목은 다음과 같습니다.
  - 로컬 테스트에서 오류가 0개입니다.
  - KaTeX 오류(빨간 글자, `.katex-error`)가 없습니다.
  - `(참조 오류: …)`가 없습니다.
  - 가로 넘침이 없습니다.
  - 데스크톱, 모바일(390px), 다크 모드 화면을 확인합니다.

## 7. 진행 방식

- 한 번에 한 장씩 씁니다. 1장부터 순서대로 진행합니다.
- 장마다 브랜치(`quantum/chNN`)를 만들고 PR을 올립니다. 머지는 사용자가 합니다.
- 장을 쓰다가 새로운 표기나 부품이 필요해지면 이 문서와 템플릿을 먼저 고친 뒤 씁니다.
