이 책의 이야기

모델의 능력과 모델 주위의 실행 시스템을 구분하며 한 단계씩 쌓습니다. 아래는 집필 전 기획이며 장의 세부 구성은 자료와 실험을 검증하면서 다듬습니다.

1부1부에서 다음 토큰을 예측하는 LLM의 원리와 대화 모델까지의 변화를 봅니다.
2부2부에서는 RLM(Reasoning Language Model)이 어려운 문제에 더 많은 계산과 검증을 쓰는 이유를 살핍니다.
3부3부의 VLM·검색·긴 문맥 처리는 서로 다른 입력과 외부 정보의 확장입니다. 에이전트를 만드는 데 모두 필요한 선행 단계는 아닙니다.
4부4부에서 모델에 도구와 상태를 붙여 행동·관찰 루프를 만듭니다.
5–6부5–6부에서는 skill, hook, workflow, subagent와 인간의 결정 지점을 조합합니다.
마지막7부에서 harness와 장기 실행 루프를 설계하고, 실행 기록과 최종 산출물로 효과를 평가합니다.
RLM의 뜻

이 책의 RLM은 Reasoning Language Model(추론형 언어모델)입니다. Recursive Language Models와 구분합니다. VLM과 RLM은 에이전트의 필수 선행 단계가 아니라 서로 다른 능력 확장입니다.

전체 목차

각 카드의 설명은 장에 들어갈 절 제목입니다. 현재 28장은 모두 빈 슬롯이며, 본문·퀴즈·실험은 아직 작성하거나 등록하지 않았습니다.

실습을 연결하는 방식

앞부분은 작은 개념 실험으로 모델의 작동을 분리해서 보고, 뒷부분은 별도의 Claude Code 연구실 작업 공간에서 ai_sci_cowork의 실제 구성요소를 관찰하고 비교할 계획입니다.

1–3부 · 모델의 능력

토큰·어텐션·추론·이미지·검색의 동작을 작은 문제로 확인합니다. 모델 내부를 직접 관찰할 수 없는 곳은 관측 가능한 입출력만 비교합니다.

4–7부 · 시스템 설계

agent, skill, hook, workflow, harness를 한 번에 모두 켜지 않고 구성요소별로 비교합니다. 같은 과제·예산·평가 기준을 사용합니다.

결과 읽기

에이전트의 완료 보고와 실제 산출물을 구분하고, 성공률과 비용, 실패 유형을 함께 기록할 예정입니다.

집필 범위

이 책은 모델의 거대한 사전학습을 재현하거나 내부 비공개 추론을 관찰하는 책이 아닙니다. 수학적 배경은 기존 선형대수와 통계 책으로 연결하고, 에이전트를 설계·검증하는 데 필요한 원리를 다룹니다.
