이 책의 지도

위 줄은 모델의 능력, 아래 줄은 모델 바깥에 세우는 실행 시스템입니다. 실선을 따라가면 빠짐없이 읽게 되고, 점선은 골라 읽을 수 있는 길입니다. 상자를 누르면 그 부의 첫 장으로 갑니다. 집필 전 기획이므로 장의 세부 구성은 자료와 실험을 검증하면서 다듬습니다.

RLM의 뜻

이 책의 RLM은 Reasoning Language Model(추론형 언어모델)이며, 문헌에서는 LRM(Large Reasoning Model)이라고도 부릅니다(Besta 외, 2025). 이름이 같은 Recursive Language Models와는 다른 것입니다.

전체 목차

각 카드의 설명은 장에 들어갈 절 제목입니다. 현재 28장은 모두 빈 슬롯이며, 본문·퀴즈·실험은 아직 작성하거나 등록하지 않았습니다.

실습을 연결하는 방식

앞부분은 작은 개념 실험으로 모델의 작동을 분리해서 보고, 뒷부분은 별도의 Claude Code 연구실 작업 공간에서 ai_sci_cowork의 실제 구성요소를 관찰하고 비교할 계획입니다.

1–3부 · 모델의 능력

토큰·어텐션·추론·이미지·검색의 동작을 작은 문제로 확인합니다. 모델 내부를 직접 관찰할 수 없는 곳은 관측 가능한 입출력만 비교합니다.

4–7부 · 시스템 설계

agent, skill, hook, workflow, harness를 한 번에 모두 켜지 않고 구성요소별로 비교합니다. 같은 과제·예산·평가 기준을 사용합니다.

결과 읽기

에이전트의 완료 보고와 실제 산출물을 구분하고, 성공률과 비용, 실패 유형을 함께 기록할 예정입니다.

집필 범위

이 책은 모델의 거대한 사전학습을 재현하거나 내부 비공개 추론을 관찰하는 책이 아닙니다. 수학적 배경은 기존 선형대수와 통계 책으로 연결하고, 에이전트를 설계·검증하는 데 필요한 원리를 다룹니다.
