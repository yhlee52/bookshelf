장기 실행 루프까지

이 책의 지도

위 줄은 모델의 능력, 아래 줄은 모델 바깥에 세우는 실행 시스템입니다. 강조한 5부에서 Claude 에이전트의 구성요소를 하나씩 봅니다. 실선을 따라가면 빠짐없이 읽게 되고, 점선은 골라 읽을 수 있는 길입니다. 상자를 누르면 그 부의 첫 장으로 갑니다. 집필 전 기획이므로 장의 세부 구성은 자료와 실험을 검증하면서 다듬습니다.

RLM의 뜻

이 책의 RLM은 Reasoning Language Model(추론형 언어모델)이며, 문헌에서는 LRM(Large Reasoning Model)이라고도 부릅니다(Besta 외, 2025). 이름이 같은 Recursive Language Models와는 다른 것입니다.

전체 목차

초고가 있는 장의 카드에는 내용 요약을, 빈 슬롯인 장의 카드에는 장에 들어갈 절 제목을 적었습니다. 현재 1–12장이 초고이고 나머지 31장은 빈 슬롯입니다.

실습과 예시

앞부분은 작은 개념 실험으로 모델의 작동을 분리해서 보고, 5부부터는 Claude Code에서 구성요소를 하나씩 작게 만들어 봅니다. 장마다 빈 폴더에서 시작하므로 앞 장의 실습 결과가 없어도 따라 할 수 있습니다.

1–4부 · 일반 원리

토큰·어텐션·추론·이미지·검색·도구 호출의 동작을 작은 문제로 확인합니다. 모델 내부를 직접 관찰할 수 없는 곳은 관측 가능한 입출력만 비교합니다.

5부 · Claude의 구성요소

CLAUDE.md, 도구와 MCP, skill, subagent, hook, 권한을 하나씩 다룹니다. 각각 무엇인지, 어떻게 작동하는지, 전체 에이전트에서 어떤 일을 맡는지 차례로 봅니다.

6–7부 · 조합과 평가

구성요소를 엮고 오래 실행한 뒤, 완료 보고와 실제 산출물을 구분해 성공률과 비용, 실패 유형을 함께 기록합니다.

8부 · Codex로 다시

5–7부와 같은 순서로 Codex 환경의 구성요소를 따로 봅니다. Claude 설명과 한 장에 섞지 않습니다.

예시 저장소

ai_sci_cowork v0.10.0은 Claude Code의 agent·skill·hook·plugin으로 만든 작은 AI 연구실 환경입니다. 이 책에서는 예시 하나로 32장 사례 연구에서 다루며, 다른 장은 이 저장소 없이도 따라 할 수 있습니다.

집필 범위

이 책은 모델의 거대한 사전학습을 재현하거나 내부 비공개 추론을 관찰하는 책이 아닙니다. 수학적 배경은 기존 선형대수와 통계 책으로 연결하고, 에이전트를 설계·검증하는 데 필요한 원리를 다룹니다.
